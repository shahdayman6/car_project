#  Car Project

A full-stack car marketplace web application that enables users to buy, sell, and rent vehicles, as well as browse and purchase spare parts through an intuitive and responsive interface.

##  Features

- Secure authentication with Admin and User roles.
- Buy, sell, and rent vehicles.
- Buy and sell spare parts.
- Upload car listings with multiple images.
- Dynamic search and filtering.
- Admin dashboard for managing users, vehicles, rentals, and spare parts.
- Complete CRUD operations.
- Responsive and user-friendly interface.

##  Technologies Used

- Laravel (PHP)
- MySQL
- Blade
- Tailwind CSS
- JavaScript
